# Planta · landing page

Página de vendas da Planta (site, CRM e portais para imobiliárias). HTML estático, sem build.

- Rodar local: `python3 -m http.server 8080` e abrir http://localhost:8080
- Publicação: GitHub Pages (branch `main`, raiz do repositório)
- Trocar o domínio do card de compartilhamento: `./set-domain.sh https://seudominio.com.br`
